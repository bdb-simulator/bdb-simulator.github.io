# 규칙·문장 대조 검사

카드 데이터와 엔진이 룰북·카드 문장과 어긋나는 곳을 찾는 도구들입니다.

| 파일 | 하는 일 |
| --- | --- |
| `keys.py` → `keys2.py` | 카드 데이터에 쓰인 효과·조건·필터 이름 중 엔진이 처리하지 않는 것 |
| `filtval.js` | 필터 값 하나하나를 전 카드에 적용해, 아무것도 거르지 않거나 아무것도 안 맞는 값 (카드명·칭호 표기 차이, 커맨드 조건이 유닛도 통과 등) |
| `zonef.py` | 패·드롭 존 등에서 고를 때 쓰이는 필터 중 처리되지 않는 것 |
| `conds.js <작품 번호>` | 상태와 무관한 조건 중 한 번도 참이 되지 않는 것 (테리토리 칭호 누락 등) |
| `run.js <작품 번호>` + `textcheck.js` | 카드 능력을 실행하며 엔진이 내민 대상 후보를 카드 원문의 조건과 대조 (결과: `/tmp/aud/<번호>.json`) |
| `rules.js` | 룰북 항목별 상황 테스트 (702·703·706·804·902·1003·1303·1304·1402) |
| `titles.js` | 테리토리 칭호 보충·표기 맞춤 확인 |

`keys2.py`는 `keys.py`가 만든 `/tmp/keys.json`을 읽으므로 `keys.py`를 먼저 실행합니다.
